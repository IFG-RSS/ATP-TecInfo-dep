# Projeto 0 — Pensar como quem programa

**Duração:** 8 aulas. **Base:** Farrer, cap. 0, seção 0.3 e exercícios de fixação 0.3.2/0.3.4.

**Estude com:** [Material 0 — Pensar como quem programa](../../materiais/00-pensamento-algoritmico.md). **Ritmo sugerido:** [aulas 1–8 no guia de avanço](../../docs/guia-de-avanco.md#projeto-0).

## Situação-problema

A escola precisa ensinar uma pessoa recém-chegada a usar o laboratório e preparar uma sequência de valores sem depender de conhecimento implícito. Como escrever instruções que destinatários diferentes executem e produzam o mesmo resultado?

## Missões

1. Classifique exemplos do cotidiano como dado, informação, conhecimento, hardware ou software e desenhe o fluxo entrada–processamento–saída.
2. Escreva instruções para uma tarefa cotidiana; outra equipe deve executá-las literalmente e registrar ambiguidades.
3. Adapte o problema das sequências pares e ímpares de Farrer: receba início, fim e paridade e gere uma sequência finita. Primeiro use linguagem natural; depois, refinamentos sucessivos e Portugol.
4. Simule compilação e interpretação com cartões de comandos e explique a diferença em até 150 palavras.

## Critérios de aceitação

O algoritmo tem estado inicial, termina, não usa comandos vagos, trata intervalo vazio e produz a sequência esperada em três testes de mesa.

**Entrega:** diário, fluxograma entrada–processamento–saída, Portugol, testes e reflexão.
